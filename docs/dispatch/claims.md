# 最終主張（已經過紅方總攻擊，為寫作唯一依據）

證據檔：results/results.json（E、v2）、results/dp_step.json（A）、results/game.json 中 "game_v2"（B；舊 "game_sweep" 屬 exploratory）、results/c_pricing.json（C）、results/d_scaling.json（D）。

每個數字都要標明它所在的 cell：N、r、shock_frac、策略集、步數、seeds。

## 主張

**C1（糾正）**
- 在 N=8、v2 下，greedy（最急優先）對所有負載都輸給 round-robin。
- 距離感知的 index：不 preempt 時只在高負載（r≥0.02）勝出；有 preempt 時在 r=.001、.002、.012 也勝。其他負載持平或略輸。（逐 r 數值見 docs/paper/number_audit.md）
- 原 README 的「資訊無價值」，主要是忽略距離造成的。
- 原 README 的定價增益，大部分來自抑制 thrash。
  - 出處：E 階段紅方的數字，cell 為 N=8、legacy、λ 固定。
  - λ* 調參後的結果見 C7。

**C2（精確 VoI，N=3，shock 0.5，spread 0.6，service 5，K=(30,60) 外推，32 seeds）**
- VoI_step = 0.012 / 0.019 [0.017, 0.021] / 0.023 / 0.018，對應 r = .002 / .004 / .008 / .016。
- 約為不可改道 DP 的 2 倍。
- 區域圖：r=.004，K=(20,30)，16 seeds。VoI_step 隨 shock_frac 單調上升（0.25 → 0.006，0.9 → 0.045），隨 spread 下降。
- 估計器有偏差：legacy 下理論上 VoI=0，實得 −0.0014 ~ −0.0025。
- **H1（VoI<0.02）不主張。**
  - 在預登記的 cell，VoI 與門檻無法區分。
  - 在 service=1 的 cell 為 0.024 [0.020, 0.028]，但同設定 f=0 的理論 0 實得 +0.002 → 扣偏差後與門檻無法區分（不寫「否證」）。
  - 估計器偏差大於餘裕。
- 「確定性衰減下 VoI=0」是構造上成立，不是發現。

**C3（round-robin 的 gap）**
- 參照是 dp_step_full，也就是免費完美資訊下的逐步最優，所以 gap 裡包含 VoI。
- N=3 的中位數：0.021（r=.002）到 0.082（r=.016）。
- N=4 的中位數：0.039 / 0.058（r=.004 / .008）。

**C4（天真信任的策略性損失，H2 成立）**
- 損失定義：truthful − 近似最佳反應剖面的 team health。
- fused_index 的損失：
  - N=3 九個 cell：0.11–0.27，例如 r=.004、f=.5、57 動作時為 0.247 [0.223, 0.272]。
  - N=8 只跑一個 cell（r=.002、f=.5、24 動作）：0.40 [0.36, 0.44]。
  - 均衡 health 相對 learned_index，所有已跑 cell 的 CI 都排除 0。
- 約為同 cell VoI_step 的 8–25 倍。
- 損失受灌水上限 b≤0.8 約束。
- D（校準負載、25 動作，exploratory）：0.165 / 0.405 / 0.413（N = 3 / 8 / 16）。從 3 到 8 上升後飽和。
- 定位：這是 cheap-talk 崩潰的定量版本，屬於驗證已知理論，不是新現象。

**C5（到達時稽核失效，H3 成立）**
- 依距離灌水（distance > 10）可以繞過到達時稽核。
- audit_index 的損失：
  - N=3、r=.004、f=.5：0.024 [0.010, 0.038]
  - N=8、r=.002、f=.5：0.042 [0.025, 0.059]
- 死亡比例：0.029 → 0.067（N=3）。
- 收斂率：0.62（N=3）、0.31（N=8），所以只能稱為「近似」。
- 少數 cell 的 CI 包含 0，例如 N=3、r=.008、f=.25。

**C6（派遣時稽核：H4 依預登記被否證、撤回）**
- audit_disp 的損失：
  - N=3：0.0027 [0.0001, 0.0052]
  - N=8：0.0058 [0.002, 0.010]
- CI 下界都 > 0，max_gain > 2·eps，所以依預登記判準被否證。
- 可以主張的說法：同 cell 下，派遣時稽核的損失約為到達時稽核的 1/7–1/9，但仍不為 0。
- 揭露：
  - max_gain 判準是樣本內的量，樣本內 0.075–0.10，樣本外只有 0.004–0.007，被選擇偏誤墊高。
  - N=8 的收斂率 ≈ 0。
  - 懲罰的誤觸發率約 40%。

**C7（定價，exploratory）**
- N=8、v2，λ* 在 seeds 0–15 上選、在 holdout 上評估。
- priced（no preempt）相對 no-thrash 基準：+0.015 / +0.045 / +0.082 / +0.092，對應 r = .002 → .016。
- 但仍輸給 honest_index 與 learned_index，約 0.03–0.07。
- 結論：λ·d 是粗糙的距離過濾。
- N=3：λ* ≈ 0（不顯著），priced 實際上等於 greedy。
- DP 的決策可以用 index 形式 τ/(d+5)^1.14 描述，top-1 準確率 0.77。
- 「λ·d 是最優策略的去中心化實作」這個假設不被支持。

**C8（規模，exploratory，負載依 N 分別校準）**
- N≥8 時，round-robin 勝過所有測試的資訊型啟發式。
- VoI 代理只回收了 DP 的 VoI_step 的 −5%～41%（index_true − learned 為 10%～41%；fused − learned 為 −5%～34%），所以 N>4 的真實 VoI 未知。
- 2 actuators 的結果無資訊量：A=1 時 fused − learned 本身就不顯著。

## 必須揭露的限制
- DP 只做到 N≤4。
- 策略族是有限集合，灌水上限 0.8。
- 預登記的網格有 27 格，實際只跑 10 格：
  - N=4 全缺。
  - N=8 只跑 r=.002、f=.5 一格。
  - 縮減的策略集與 eps 列在 decisions.md。
- 調參只在一個 cell 上做。
- shock_rate、σ=0.15、AR φ=0.9 都只取單一值。
- health 會 clip 在 0：近似均衡下的死亡比例很高，損失可能主要反映死亡。
- 服務不可中斷。
- 損失基準不一致：H2 對 learned_index，H3、H4 對各自的 truthful。

## 新意定位
- 最站得住的兩條：
  1. 精確逐步 DP 給出旅行耦合下的 VoI，以及它隨 shock 的相圖。
  2. 稽核時機：到達時稽核會被依距離灌水繞過；派遣時稽核把損失降約一個數量級，但沒有消除。
- 已知理論的定量驗證（不當成新發現）：C4 對應 cheap talk，C7 對應 Naor toll，C1 對應 DTRP。
