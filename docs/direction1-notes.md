# 方向一：查核時機——文獻調查與決策紀錄

## 2026-10-06：第一輪文獻調查（兩路平行，只讀摘要層級）

### 共同結論
- 兩路調查都沒有找到明確處理「稽核決策相關的宣稱」與「稽核驗證當下的宣稱」之差別的文獻。
- 原因：前人模型中的型別要嘛是靜態的，要嘛在回報與驗證之間不變。在這種情況下，兩種稽核做法等價，這個問題根本不會出現。
- 搜尋並非窮盡，「找不到」不等於「不存在」。

### 最接近、可以在其基礎上延伸的前人研究
- **Dai, Blanchard, Jaillet（COLT 2025, arXiv:2502.08412）**：無貨幣的重複分配，分配之後才稽核被採用的那筆宣稱，給出 O(K²) 後悔與 O(K³ log T) 次稽核。型別是否 i.i.d. 尚未核實。
- **Li（2020, JET 186）**：成本性驗證加有限懲罰，最優機制為雙門檻結構。靜態模型，稽核的是已被採用的宣稱。
- **Ravikumar & Zhang（2010）**：動態稅務稽核，狀態在回報後會演化，最優稽核依報告的持續期決定。單一 agent，沒有稀缺資源。
- **其他相關**：
  - Mylovanov & Zapechelnyuk（2017）
  - Ben-Porath, Dekel, Lipman（2014, 2019）
  - Caragiannis 等（EC'12，probabilistic verification）
  - Estornell, Das, Vorobeychik（AAAI 2021，strategic classification 中的稽核）
  - Gao, Wright, Leyton-Brown（limited ground truth）
  - Braverman 等（COLT 2019，strategic arms）
  - Nath 等（UAI 2011，動態兩階段機制）
  - Wang（2005）與 Popov（2016）的 dynamic CSV
  - Avenhaus, von Stengel, Zamir（inspection games）

### commander 的擬議切入點（推論，尚未檢驗）
- **分離**：在「狀態會演化、回報可隨時更新」的模型下，兩種稽核做法分開。驗證當下稽核存在一個不被抓的策略：遠時灌水、近時說實話。
- **取捨（核心）**：
  - 派遣時稽核擋得住時機操縱，但會因旅行期間的狀態漂移而誤判誠實者。實測誤觸發率約 40%。
  - 到達時稽核沒有漂移問題，但可以被操縱。
  - 因此最優的稽核時機或容忍帶，取決於「操縱空間」與「漂移誤判」之間的取捨，關鍵量大約是「衰減率 × 旅行時間」。

### 紅方（新穎性）結果與判斷
- 「分離只是建模選擇的後果」：部分成立。到達時稽核可被利用，只是一個構造性反例，降級為引理。
- 「與 window dressing 同構，已知解法是隨機突襲時點」：成立，但它同時指出真正的新意。
  - 本設定中，觀察真相需要服務者親自到場。
  - 服務者的接近可以被觀察，而且由分配決策決定。
  - 因此隨機突襲在本設定中不可行。這是紅方救援條件 (a)：查核時點內生於分配。
- 「取捨只是型一／型二錯誤」：部分成立。需要給出閉式的最優容忍帶，並呈現質的變化。
- 相對 Dai 等人的增量取決於他們的型別假設，等全文核對結果。

### 修正後框架（commander 推論，待白方檢查）
- 「到場才能查核」使查核時點可被預測、且內生於分配，所以隨機突襲不可行。機制只能稽核決策當下的宣稱，代價是旅行期間的狀態漂移。
- 目標定理：
  - 「使用回報＋派遣時稽核」優於「忽略回報」的充要條件，形式大約是 VoI > 漂移誤判成本(τ)。
  - 存在一個旅行時間門檻 τ*，超過它時忽略回報為最優（相變）。
- 基線：
  - 隨機時點稽核（假設可以突襲的理想情況）
  - Dai 等人的機制
  - 決策時稽核
  - 忽略回報

### 全文核對結果（2026-10-06）
- **Dai–Blanchard–Jaillet**（arXiv v3，2026-05，新標題 "Non-Monetary Mechanism Design without Priors: Achieving Efficiency via Adaptive Costly Audits"）
  - 型別 i.i.d.（§3.1, p.7）。
  - 稽核贏家，並在同一輪揭露真實效用（Assumption 1, p.8）。
  - 懲罰為永久排除（p.11）。
  - Thm 2：AdaAudit 的 R_T ≤ K²，B_T = O(K³ log T / c)。Thm 8 給出下界。
  - Future work 沒有提到動態狀態或驗證時點。
- **Li 2020**：完全靜態；驗證完美揭露型別；有限懲罰；雙門檻 pooling 結構。
- **Ravikumar–Zhang 2010**：Poisson 單調吸收態；委託人事前承諾稽核到達率；最優為「前 N 期不稽核，之後隨機稽核」。狀態只有單調變化，agent 唯一的策略是延遲回報。
- **三篇共同缺口**：沒有處理非單調演化的狀態，也沒有處理 agent 依時間或距離策略性修改回報。

### 乾淨漏洞（commander 推論，待證）
- 把 Dai 等人的 AdaAudit（同輪比對、永久排除）放到狀態演化的環境，誠實 agent 會因漂移被誤判並被永久排除，後悔可能由 O(K²) 退化為 Θ(T)。
- 修正方向：漂移容忍帶加上有限、可寬恕的懲罰，目標是恢復與 T 無關或次線性的後悔界。

### 白方意見（2026-10-06）與採納
- 定理 B 有稻草人風險。只把型別改成 Markov 不夠，還必須加上驗證延遲 τ>0。敘事改為「在放寬假設下的脆弱性＋修補」，貢獻在修補。
- 定理 A 原本的形式太平凡。需要給出 τ* 的閉式解或單一交點，並改寫成「殘差方差」版本，因為派遣時稽核已經扣掉了預期漂移。
- 「隨機突襲不可行」說得太滿，應該說「可以做，但要付旅行成本」。因此是三方取捨：操縱空間、漂移誤判、突襲的旅行成本。
- 白方提出的替代基線，以下兩個已經做過，可以直接用：
  - 漂移扣除：audit_disp 本身就已經扣除。
  - 到達稽核＋跨期懲罰：H3 的懲罰變體在 N=8 時損失約 0.05，仍然失效。
- 最小可發表版本：K=2、二元 Markov 狀態、固定 τ、離散時間。目標場地為 EC／AAMAS workshop 或 WINE。

### 分階段計畫（使用者同意，2026-10-06）
1. **2×2 實驗**：{i.i.d., Markov} × {τ=0, τ>0} 跑 Dai 等人的稽核機制（固定 p 版與 AdaAudit，永久排除）。
   - 通過標準：只有 Markov×τ>0 退化，表現為誠實者被誤排除、後悔隨 T 增長。
2. **修補**：漂移容忍帶＋可寬恕的有限懲罰；加入基線並量化三方取捨。
3. **理論**：在最小模型推導脆弱性、修補後的後悔上界、τ* 的閉式特例。關鍵機率要和使用者一起手算。
4. **寫作**：先和使用者確認範圍再寫。

### 階段 1 結果（2026-10-06）：假設不成立 → 診斷並修正理解
- 實作逐字照論文，一致性檢查通過：i.i.d.×τ=0 時 R_T=0，AdaAudit 的 B_T 增長符合 log T 理論。
- 結果：只要 τ≥1，不論 i.i.d. 或 Markov、不論 ρ，誠實者 100% 被排除，R_T/T≈0.81。
- 診斷：
  - 原因是零容忍比對（固定 p 版要求 w≠v，AdaAudit 要求 v>w）加上不同時刻的效用必然不同。這幾乎是顯然的，證實了白方警告的稻草人風險。不能當成貢獻。
  - i.i.d.×τ>0 時，延遲驗證與回報獨立，比對本身沒有意義。
- 修正後的理解（commander 推論）：
  - 控制量是延遲驗證的資訊量 ρ^τ，也就是 corr(u_t, u_{t+τ})。
  - 有意義的問題是「加入容忍度 δ 之後」：誤判誠實者與漏抓說謊者的取捨由 ρ^τ 與灌水量 b 決定，可能存在相變。
  - 稽核次數的規模也重要：固定 p 版約 pT 次，任何正的誤判率都會讓誠實者最終陣亡；AdaAudit 約 log T 次，誠實者可能存活。這是非顯然的差異。
- 決定：不進入階段 2。先派紅方攻擊階段 1，並做階段 1b（固定容忍度 δ 的 ρ×τ×δ 掃描，比較固定 p 與 AdaAudit）。

### 階段 1b 結果（2026-10-06，results/adaaudit_tol.json，fig17a–c）
- **一致性**：δ=0 時與階段 1 逐位元相同。
- **推論 1，部分成立**：
  - 單次誤判率只由 ρ^τ 決定。這是代數恆等式，不是發現。
  - 動態結果（存活率、抓出率）只近似疊合，ρ 還透過估計期與稽核的聚集發揮作用。
  - 結論：ρ^τ 是一階控制量，不是唯一控制量。
- **推論 2，修正**：
  - AdaAudit 的誠實者衰減較慢（約 log T 型），但仍在衰減。「可能存活」只在有限 T 成立，收回。
  - T<~3e4 時，AdaAudit 的稽核次數反而比固定 p 多。
  - 沒有發現誤判後的連鎖效應。
- **相變候選**：
  - 「固定 δ＋永久排除」要可行，需要 ρ^τ ≳ 0.90–0.95，可行點只有網格解析度。
  - 抓出率被誤殺污染，必須改用超額抓出率（catch_excess_over_honest_exclusion）重算。
- **擬議命題（commander 推論，待證）**：在 ρ^τ<1 下，任何「門檻檢定＋永久排除」機制的誠實者存活率都 → 0。
  - 固定 p 版約為 exp(−q·pT)。
  - log 次稽核版約為 T^{−Θ(q)}。
  - 根源在「永久」排除。階段 2 的修補重點因此放在可寬恕的有限懲罰。

### 紅方（階段 1）結果與判斷（2026-10-06）
- 實作大致忠實。未發現逐行差異；Markov copula 正確。
- **R/T≈0.81**：來自「全員被排除→不分配→效用記 0」的慣例（adaaudit.py:105-107）。論文未定義此情況。此後一律報兩種 fallback（不分配／隨機分配）。
- **「AdaAudit 較耐受」被證偽，收回**：δ=0.2 時兩者存活率相同，δ=0.1 時 AdaAudit 更早死。
- **新線索**：Markov×τ=0 時，AdaAudit 的 B_T 從 3642 升到 5624（ρ=0.9）。原因是 q̂ 自相關觸發 Def.9 旗標並重啟估計期。這可能是獨立於延遲的脆弱性，即 log T 稽核保證在型別有持續性時失效。列入階段 2 量測。
- **控制量修正**：u 空間的相關不等於 ρ^τ，改用 z 空間的 ρ^τ，並同時列出 rank 相關。
- **誤判率修正**：贏家選擇偏誤使 P(v>w|贏家) > 1/2（實測 0.573／0.522）。
- R_T=0 與 revpast 控制組屬同義反覆，不作為忠實度證據。真正的檢查是 late liar 的 R=2.63 ≤ K²。

### 階段 1 結案判定
- 原通過標準不成立。依規則已完成診斷，並修正理解：
  1. 零容忍＋延遲的失效是顯然的。
  2. 真正的脆弱性在「永久排除」：只要誤判率為正，誠實者就會逐步陣亡，兩種稽核版本都一樣。
  3. 待查：AdaAudit 的估計器在持續型別下失準，稽核次數上升。
- 據此進入階段 2，已把上述修正事項通知階段 2 的 agent。

### 重新框架候選（commander 推論，待白方檢查與 2b 實驗）
- 驗證有雜訊時（σ_τ = √(1−ρ^{2τ})），稽核在「誤罰誠實者」與「偵測小幅灌水」之間有根本取捨（Neyman–Pearson）。
- 小幅灌水會翻轉邊緣分配，帶來一階得利。
- 目標：刻畫前沿「誤罰率 α → 最大說謊得利 G*(α, σ_τ)」，含兩部分：
  - 下界（不可能性）
  - 可達性：CUSUM 或其他檢定逼近這條前沿
- 到達時稽核則無論如何都被時機灌水擊敗。
- 階段 2b：修正 M4、擴大策略集（含不需對手資訊的邊緣灌水）、量出前沿並檢查是否隨 σ_τ 縮放。

### 白方（重新框架檢查）與事前否證條件
寫於 2026-10-06，在看到階段 2b 結果之前。

白方判斷：轉向 2、3 由證據推動，屬誠實收回；但轉向 4 有「追敘事」風險，因為每次都放寬到沒有反例為止。新框架的核心（小於雜訊的偏差測不出、小偏差帶來一階得利）大部分屬已知：
- 統計常識＋包絡定理
- probabilistic verification 文獻（Caragiannis 等；arXiv 1804.10512、1908.05556）

可能的新意在：
- 得利為一階（d·f），偵測力為二階（d²/σ²），兩者有冪次差
- 重複博弈中 CUSUM 的偵測延遲
- 無資訊策略能達到 oracle 得利的比例
- 延遲造成的 σ_τ 依賴與可寬恕懲罰之間的取捨

**否證條件**（任一 F1 或 F3 成立，即停止新框架；**不允許第 5 次重新框架**）：
- **F1**：固定 α 下，G*(α) 對 σ_τ 的 log-log 斜率與 1 的差距超出 CI；或 ρ、τ 分開掃描時不疊合。若成立，則「σ_τ 縮放」不成立。
- **F2**：α→小時，G* 不趨近 0 或不隨 α 單調。若成立，則前沿不是 Neyman–Pearson 型。
- **F3**：無資訊版邊緣灌水的得利 ≤ 約 2 個標準誤。若成立，則一階得利只是 oracle 假象，框架撤回。
- **F4**：任何檢定（CUSUM、LR、窗口檢定）都達不到下界的常數倍以內。若成立，則可達性不成立，只剩下界，而且很可能是已知結果。

### 文獻核對：小謊言與無驗證機制（2026-10-06）
- 沒有找到證明完整命題的文獻（一階得利 d·f 對二階偵測 d²/σ²、含 σ 與 α 的界）。但序貫分析本身是標準統計；Green–Porter、Abreu–Pearce–Stacchetti 傳統可能隱含相同直覺，尚未查證。
- 已知部分：
  - Caragiannis 等（EC'12）：偵測機率可依謊言距離而變，但需要付款。
  - Ball–Kattwinkel（TE）：連續的驗證能力。
  - Ferraioli–Ventre（IJCAI'18）：OSP 加 probabilistic verification。
  - Radner 1985、FLM 1994：重複賽局中的 review strategy 與 folk theorem。
- **最大威脅：配額（linking）機制**
  - Jackson–Sonnenschein（Econometrica 2007）：i.i.d. 型別，不需貨幣、不需驗證，可達近似 IC，但沒有收斂速度。
  - Escobar–Toikka（Econometrica 2013）：推廣到 Markov 私有型別。
- 決定：無論走 (a) 或 (b)，都必須把配額機制當基線正面比較。推論：配額只約束頻率，可能擋不住小幅邊緣灌水，待實驗驗證。

### 階段 2b 結果（2026-10-06，results/stage2b.json，fig19a–d）與否證判定
- **一致性**：與紅方的數字逐位元相同；誤判率 = Φ(−κ)。
- **F1 成立**：σ 縮放不成立。G=cσ^s 的 s 在 α=0.005 為 1.26 [1.13, 1.39]，在 α=0.05 為 2.18 [1.77, 2.63]。ρ、τ 分開掃描時疊合：前沿只由 r 決定。
- **F2 部分成立**：前沿單調遞減，在有限的 α_0 處降到 0。
- **F3 成立**：
  - 無資訊邊緣灌水只在 r≤0.8 有效（r=0.5 為 +0.026，約 oracle 的 27%），且不比單純的 dz 細水長流好。
  - r≥0.9 時 ≈0 或為負。一階得利主要是 oracle 假象。
- **F4 無法判定**：四種檢定的表現在 1.5 倍以內，沒有推導下界。
- **依事前規則**：F1、F3 成立，停止「雜訊前沿」框架，不允許第 5 次重新框架。理論方向 (a) 終止。
- **正面結果**：修正後的 M4（突襲對象包含得標者）在 ε=0.005 時，六個 r 下都嚇阻說謊，R/T ≈ 0.01–0.02，α=0。不可預測的即時突襲比延遲驗證上的統計檢定便宜且穩健，推翻了最初「突襲不可行」的直覺（在抽象模型中，突襲成本為浪費一輪）。
- **ρ 錯設**：低估 ρ 時說謊得利上升（0.055）；高估時誠實者大量被誤罰（α 0.63–0.98）。

### 配額機制基線（2026-10-06，results/quota.json，fig20a–c）
T=1e5，評估 seeds 5000–5031，ρ^τ = 0.5/0.8/0.9/0.99。G 分兩欄：非 oracle 策略／含 oracle 策略。

| 機制 | 誠實 R/T | G（非 oracle） | G（含 oracle） |
|---|---|---|---|
| NAIVE（直接相信回報） | 0 | 0.28 | 0.28 |
| M0 | 0.224 | 0 | 0 |
| M3C | 0.000–0.008 | 0.002–0.021 | 0.02–0.09（邊緣灌水） |
| M4 修正版 | 0.016（各 r 相同） | 0 | 0 |
| QM（J-S 邊際配額），W=1000 | 0.007／0.012／0.017／0.059 | ≤0.005 | ≈0.10–0.15（保留高分位額度） |
| QT／QE（E-T 式） | 0.004–0.011 | 0.03–0.12 | 0.07–0.14 |

- QM 擋得住無資訊的小幅灌水，與原本的推論相反。但 QM 擋不住 oracle 策略。
- QM 的效率損失來自型別持續性：誠實回報被改寫 4%–65%，ρ^τ 越高、W 越小越嚴重。
- 實作簡化：沒做 J-S 的 g^K 校正與防共謀；E-T 只條件於自己的前一期報告；ρ 為 oracle。

### 方向一實證總結（「脆弱性地圖」，commander 綜合）
- 天真信任：G=0.28。
- 到達時稽核：被時機灌水擊敗，G≈0.28。
- 派遣時稽核：後悔很低；對無資訊說謊者得利很小，對 oracle 邊緣灌水得利 0.02–0.09；對 ρ 錯設很敏感。
- 低機率突襲（含得標者）：G=0，R≈0.016，對 ρ^τ 不敏感，是最穩健的選項。
- 配額機制：對無資訊說謊者有效；對 oracle 策略失效；型別持續性高時效率損失大。
- 反覆出現的弱點：策略集有限（oracle 策略主導；自適應策略實作偏弱）。這正是方向二（RL 對手）要解決的問題。
