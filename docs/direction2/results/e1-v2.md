# E1 v2 結果：學習型防守方修補的預先登記確認（2026-10）

**一句話結論：** 在固定 M3C、r=0.5、p=0.1 下，預先登記的最終候選 C2 在 1024 個全新 test seeds 上，誠實服務代價守住上限（H 成立），但對「AS 選出的最強攻擊者 a\*」的增益降幅只有 0.004236（單側 95% 下界 0.003883、上界 0.004589），統計上排除了達到 δ=0.005 的降幅；依決策樹判為「效果不足：排除達到 0.005 的降幅」，不構成修補。

尺度：G＝攻擊者策略相對誠實基準策略多拿到的私利（逐 seed 的每步效用差，於記分窗平均；與 `conclusion.md` 的「相對基準取得額外私利」同義，實作見 `scripts/e1_pilot.py::metrics`）。降幅約為原設定下 a\* 增益 0.0348 的 12%（0.004236/0.034755）；統計上確定有降，但沒有達到預先約定的 0.005。

來源簡寫：設計＝`docs/direction2/design/e1-v2.md`；impl＝`docs/direction2/design/e1-v2-impl-notes.md`；res＝`results/direction2/e1v2/result.json`；sec＝`.../secondary.json`；sel＝`.../selection_frozen.json`；cand＝`.../candidates.json`；sat＝`.../saturation.json`；tc＝`.../testcheck.json`；led＝`.../test/ledger.json`；fr＝`.../freeze_record.json`；man＝`.../manifest.json`；raw＝`.../test/*_raw.json` 與 `.../evaluations/*.json`；v1＝`docs/direction2/results/e1-pilot.md`。表中數字取自上述檔案；標「推論」者為由數字推得、未直接量測；標「重算」者為本文由原始逐 seed 資料（`scripts/e1_pilot.py::metrics`，與 `scripts/e1_v2.py::compute_result` 同法）或檔內數字做的算術。

## 1. 登記的判準與命中的節點

設計 §1 的唯一主要判準：test（n=1024）上，逐 seed 配對差 D_s＝G_orig(a\*_orig; s)−G_C\*(a\*_C\*; s) 的單側 95% 下界 LB>δ=0.005（E），且誠實 regret 差與不合格比例差的單側 95% 上界各自 ≤ 0.002、0.01（H）；兩者皆過才稱「修補成立」。設計 §5 決策樹以 H、E 的真假決定結果。

| 項目 | 值 | 判斷 |
|---|---|---|
| H（誠實約束） | `true`（見 §3） | 成立 |
| E（LB>0.005） | LB＝0.003883 | 不成立（`false`） |
| 命中節點 | 「H 且非 E」→ 效果不足 | 子標籤依序判斷 |
| 子標籤 (a)：UB_D<0.005？ | UB_D＝0.004589<0.005 | 命中，標籤＝(a)「效果不足：排除達到 0.005 的降幅」 |
| 另列：LB>0？ | `true`（0.003883>0） | 事實，不改標籤（設計 §5 第 6 點） |

`res.category = "insufficient_effect"`、`res.sub = "a"`。LB 與 UB_D 用同一個 t 臨界值（df=1023，t=1.6463）、各是單側 95% 界；兩者合起來是 **90% 雙側區間 [0.003883, 0.004589]**，不是 95% 雙側 CI。δ、上限、a\*、候選、seeds 數在看到 test 前都已凍結，結果出來後沒有更動。

## 2. 主結果

主判定只評兩個固定對象：原設定下的 a\*（`orig_adapt0`），與 C2 下的 a\*（同為 `orig_adapt0`；見 §4）。a\* 是在 AS（n=128）上、12 個條目中取 G 最大者，所以「最強」只在 AS 上成立，不保證在 test 上仍是最強（見 §5）。

|---|---|---|
| test seeds | 72400000–72401023，n=1024 | man `seeds.TEST`、res `n` |
| G_orig（原設定下 a\*） | 0.034755 | res `G_orig_mean` |
| G_C2（C2 下同一 a\*） | 0.030519 | res `G_cand_mean` |
| mean D | 0.004236 | res `mean_D`（＝0.034755−0.030519，重算吻合） |
| 單側 95% 下界 LB | 0.003883 | res `LB` |
| 單側 95% 上界 UB_D | 0.004589 | res `UB_D` |
| δ | 0.005 | res `delta` |
| 逐 seed SD(D)（重算） | 0.006862；SE＝0.000214 | test raw `orig_main_raw.json`、`cand_main_raw.json` |
| C2 在 a\* 下的殘餘 G，95% 雙側 CI（t，df=1023，重算；設計 §1 次要結果 2） | 0.030519 [0.029745, 0.031292] | test raw；對 0 的距離，不等於「已修補完」 |
| 原設定 a\* 的 G，95% 雙側 CI（重算） | 0.034755 [0.034010, 0.035500] | test raw |

兩個旗標：`attack_may_be_unsaturated` 對原設定、C1、C2 皆為 `false`；`L_at_upper_bound=false`；`graph_fallback_used=false`（res）。

**區間比設計假設窄。** 設計 §6 的檢定力計算假設逐 seed σ_D＝0.0135 或 0.015；test raw 重算的實際 SD(D)＝0.006862（與由 LB 反推的 (0.004236−0.003883)/1.6463×√1024≈0.0069 一致），約為假設的一半，所以區間窄、能排除 0.005。

**AS 與 test 的差異：AS 低估了 C2 的降幅，原因未定。** 從 AS raw（sel `transfer_matrix_AS` 所指的 `evaluations/*.json`）以同法重算 a\* 的逐 seed 配對 D：

| | n | mean D | SD(D) | SE |
|---|---|---|---|---|
| AS | 128 | 0.002631 | 0.007313 | 0.000646 |
| test | 1024 | 0.004236 | 0.006862 | 0.000214 |

差 0.001606；組合 SE＝√(0.000646²+0.000214²)＝0.000681（重算）；差約 2.36 個 SE。兩側各自的變化（a\* 的平均 G，AS→test）：

| | AS（n=128） | test（n=1024） | 變化 |
|---|---|---|---|
| 原設定 a\* | 0.03647 | 0.03476 | −0.00171 |
| C2 a\* | 0.03384 | 0.03052 | −0.00332 |

（AS 上單一 G 的 SE 約 0.0010–0.0011；test 約 0.0004。）兩側都比 AS 低，C2 側降得更多，所以 D 在 test 上比 AS 大。原設定側的縮水，與 a\* 是平坦軌跡上的最大值一致（推論，見 §4），但 C2 側為何降得更多、以及 AS 與 test 差約 2.4 SE 的來源，本實驗沒有直接證據；不應歸為「雜訊範圍內」。

**飽和（sat）。** 九條鏈的「最後 40 代最佳減前 200 代最佳」增益全部為負，範圍約 −0.00008 至 −0.00095（門檻 0.001），**依登記規則判為飽和**，`extend=false`，未延長；warm-start 不對稱（§6.1）使攻擊端對候選可能偏弱：若如此，真實降幅可能比測到的更小，不改變「效果不足」的方向，但「C2 下最強攻擊者」的界定仍不完整；三防守的 `attack_may_be_unsaturated` 皆 `false`。注意：這只表示最後 40 代沒有比前 200 代更好；它**不等於**「優化器有效改進過攻擊」。上表顯示軌跡是抖動而非上升，也可能是搜尋在起點附近沒有找到更好的方向（兩種解釋本實驗區分不了）。

## 6. 限制

1. **warm-start 不對稱（設計 §4、§11）。** 三個 frozen 起點是針對原設定訓練的；對原設定已是近最佳回應，對 C1／C2 需要重新適應。同樣 240 代的預算對候選防守可能偏不利於攻擊者，使候選看起來比真實更安全。飽和規則只能減輕、不能排除這點。若攻擊端對候選偏弱，真實降幅可能比測到的更小，因此不改變「效果不足」的方向；但「C2 下最強攻擊者」的界定仍不完整。
2. **a\* 全是原設定攻擊者。** 三個防守的 a\* 都是 `orig_adapt0`，且數條鏈的最佳點就是起點，各鏈軌跡抖動而無上升趨勢。對 C1、C2 的重新適應在本預算內沒有找到更強攻擊；可能是 C1、C2 本身較難利用，也可能是適應預算或 warm-start 不足，**本實驗無法區分**（推論）。降幅 0.0042 因此是「AS 選出的 a\* 被 C2 壓低的量」，不是「C2 下最強攻擊者」的完整界定。
3. **只有兩輪 defender→attacker。** 不是收斂、不是均衡。
4. **範圍窄。** 限 M3C、r=0.5、p=0.1、公開資訊 55 參數攻擊模型、h∈[4,8]、κ_ref∈[0.35,0.65]、L∈[1000,5000]；結果不外推到其他機制、r 或 p。
5. **進 test 的只有一個候選（C2），主判定的對手只有一個固定 a\*。** 「最強」指 AS 上 12 個條目（9 個不同參數）中最強，不是所有可能攻擊者；test 上最強者另見 §5。
6. **AS 與 test 的差距未解（§2）。** AS 低估 C2 降幅約 2.4 個組合 SE，原因未定；這也表示 AS 上的選模排序（如 C2 對 C1 只差 0.00087）可靠度有限。
7. **誠實策略路徑**（impl A.7）：DT/DS 用 `AdapterPolicy({})`，test 用零參數 `MLPPolicy`，理論輸出相同，但 ΔR 絕對水準可能略異（推論，未驗證）。訓練期誠實約束用 n=16 點估計（impl A.2），只有 DS 選模用 CI。
8. **S1 的 planted-exploit 檢測力仍未在改機制後檢驗**（設計 §11）；殘餘 G 低也可能是攻擊者池不足。

## 7. 可以宣稱／不能宣稱

可以宣稱（限本設計的範圍）：
1. 在 M3C、r=0.5、p=0.1 與本攻擊者預算下，C2 相對原設定降低 AS 選出的最強攻擊者 a\* 的平均增益 0.004236，單側 95% 下界 0.003883>0。（LB>0 是另列事實，不改判定，不代表部分修補成立。）
2. 該降幅的單側 95% 上界 0.004589<0.005，故排除了達到預登記實質門檻 0.005 的降幅；決策樹結果為「效果不足」。
3. C2 的誠實服務代價（test 上）regret +0.001173、不合格比例 +0.004628，單側 95% 上界 0.001283、0.005032，皆在 0.002、0.01 之內。
4. 在 12 個條目（9 個不同參數）上，C2 的降幅落在 0.0033–0.0043，LB 皆>0（描述性，未校正）。
5. 九條適應鏈依登記的飽和規則皆判飽和；但這不等於優化器有效改進（§4）。

不能宣稱：
- 「修補成功」「修補成立」：主判定未達 E。
- Nash、收斂、均衡（只有兩輪）。
- 「最強攻擊」：只是 AS 選出的 a\*；warm-start 對原設定與候選不對稱，攻擊端對 C1／C2 可能偏弱；test 上最強條目與 a\* 也不同。
- 通用修補或跨機制、跨 r、跨 p 的結論；真實機器人、重新訓練成功率。
- 誠實使用者「無代價」：只確認上界在上限內，點估計為正，非等效檢定。
- 殘餘 G 為零，或與舊 97500 記分窗的絕對值互比（本版記分窗為 T−5000）。
- S1 已重新標定，或改機制後的 planted-exploit 檢測力。
- 以次要結果取代或翻轉主判定。

與主實驗結論的關係：本結果不改 `conclusion.md` 的「原設定下學習策略有額外私利」（D=+0.010778，64 seeds）；它回答另一個問題，即修補是否達到預登記門檻。

## 8. 這個結果的意義

在 h、κ_ref、L 三個旋鈕的搜尋空間內，目前有兩個描述性對照點：

| | 降幅（AS／驗證選出的最強攻擊者） | 區間口徑 | 誠實代價 | 證據性質 |
|---|---|---|---|---|
| v1 pooled | 0.0086 | 95% 雙側 CI [0.0047, 0.0125] | regret +0.00179、不合格 +0.00653；CI 上界 0.0033／0.0118 越過上限 | 探索性、validation 32 seeds、選模同批 |
| v2 C2 | 0.004236 | 90% 雙側區間 [0.003883, 0.004589]（兩個單側 95% 界） | regret +0.001173、不合格 +0.004628；單側 95% 上界在上限內 | 預先登記、全新 test 1024 seeds |

v1 與 v2 的攻擊者集合、seeds、n、選模方式都不同，所以這兩個點不能當作同一條取捨曲線上的嚴格兩點，只是兩個描述性對照：v1 的點估計降幅較大、誠實代價 CI 越線；v2 的誠實代價守住、降幅約一半且排除了 0.005。在已評估的兩個點中，沒有任何一個同時滿足「降幅統計上超過 0.005」與「誠實代價在上限內」；只有兩個點（v1 為探索性且未過誠實約束，v2 只有一個候選進 test），不足以推論搜尋空間內不存在這樣的設定。設計 §10 登記時已寫明「成立」不是預設結果。這不是前緣的完整描繪，且限制 §6.2、§6.6 提醒降幅與攻擊端的強度本身都有不確定性。
