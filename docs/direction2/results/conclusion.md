# 方向二：本階段結論與收尾

註（2026-10-19）：本文保留 holdout 收尾時的狀態；之後完成的 E1 v2 防守修補結果見 [e1-v2.md](e1-v2.md)（判定：效果不足）。

在固定 M3C、r=0.5 下，這個只看公開資訊的學習策略，相對固定手寫基準取得了額外私利；原登記的 J3 判定成立，另行登記的新環境 holdout 在固定的門檻下支持這個有限範圍的結論。

主要數字：**D=+0.010778 [+0.007362, +0.014194]**，64 個新 seeds；對 δ=0.005 的結果為 **確認實質優勢**。三個既有 run 的次要同時區間有 3/3 高於零，表示這三個固定模型的方向一致性。

**這個 holdout 的登記時點。** 它不是原 spec 的預先登記結果：協定與 δ 在主實驗 test 結果出現之後才登記（commit `436424b`，在 holdout 執行前）。δ=0.005 沿用 post-main 診斷的效應尺度，不是 spec 的 MDE 門檻；64 seeds 的檢定力以 validation 的 D 估計。因此 δ 是「在主實驗之後另行登記、於執行前固定的門檻」，「確認實質優勢」只在這個意義下成立。需要 holdout 的原因：主實驗 run0 的策略權重與 S1 的 D2 兩格完全相同（`results/direction2/main.json` 的 `prior_identical_policies`），同一組 test seeds 已在 S1 用過，原 test 對 run0 不是新增獨立證據。

| 證據 | 主 run0 的 D [95% CI] | 解讀範圍 |
|---|---|---|
| 原正式 test | +0.013657 [+0.009315, +0.017999] | 原 J3 保留；run0 曾在 S1 使用相同 test |
| validation 尾端誠實診斷 | +0.009126 [+0.005812, +0.012440] | 事後診斷，非獨立確認 |
| 新環境 holdout | +0.010778 [+0.007362, +0.014194] | 策略與判準先固定的新環境確認 |

機制解釋目前到這裡：既有消融顯示，三個固定策略都依賴當期型別、停權／資格與殘差資訊；低急迫度時加報較多，最高急迫度區間平均略微低報。這支持狀態相關的報告策略，但還沒有把各項調整如何產生淨收益完整拆開。

本階段已可形成研究結論並整理論文。結論限制為這個固定 M3C、固定公開資訊模型與固定手寫基準；不代表所有機制、所有手寫策略或最強攻擊，也不代表新訓練的成功率。S1 的基礎優勢混淆是限制，具體如下。

**S1 閘門與 J3 的前提。** J3 的前提是 S1 閘門通過。S1 依原登記規則族外 3/3 通過，J3 依 spec §9.2 的字面規則因此成立。但事後 off-knob 診斷（探索性，只用 val／val2）顯示，只有 D1、O1 有利用漏洞的證據（E 的 CI 下界>0），以利用證據計族外為 2/3，未達登錄的 3/3。D2 是偵測規則的偽陽性：兩格為同一 checkpoint，E=0，detected 來自 RL 在基礎機制上的優勢；盲區 O5 也是（E≈0）。因此 S1 對檢測力的說法變弱：不能無限定地宣稱「RL 找回族外漏洞 3/3」，也不能由 S1 推論對其他漏洞的檢測率。細節見 [S1 結果](s1.md)。

若接著研究防守，應另訂「哪項機制修改能降低攻擊者增益，同時不惡化誠實使用者的服務」的目標與門檻。那是下一個問題，不是這次結論的無限延長；這批不自動開始訓練。
