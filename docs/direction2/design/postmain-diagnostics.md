# 主實驗後診斷協定（執行前登記，2026-10-13）

目的：補 REQ-ENV-20 的截斷偏差量測，並描述固定 M3C 上已學到的報告策略。這是看過主實驗結果後提出的診斷，全部使用 validation 2000–2031；不是新 holdout，不重新選 checkpoint、不重訓，不改正式 test、ledger 或 J3。原評估數值程式保持不變。

## 截斷偏差

- 兩個 main cell（r=0.5、0.9），各取已由 validation 選定的主 run 與公開手寫基準。
- T=100000、L=2500、T_score=97500、32 個 validation seeds。正常值直接讀取已存的 validation 效用快照；診斷變體用既有 `env.simulate(..., diagnostic_variant="tail_honest")`，在 t>T−2L 強制誠實。模型、其他參數、亂數與事件順序均相同。
- 每個 seed 計算 G_normal、G_variant、ΔG_trunc，報配對 t(31) 95% CI。誠實策略快照必須與正常基準一致。另報 ΔD_trunc=ΔG_RL−ΔG_HW，說明比較差值受尾端處理影響的量級；不拿它修正正式 test。
- 門檻沿用各政策已凍結的 validation G-MDE（不是 test 重估，也不是 RL/HW 共用一個 MDE）。REQ-ENV-20 的「CI 下界 >0 且 ≥MDE」依字面計算 lower-bound 判準；另完整列出 mean≥MDE 且 lower>0 的較寬判準，避免語意混淆。未跨門檻不代表零偏差。
- 此變體同時移除末端攻擊收益及其後續影響，只是原規格規定的偏差近似，不能當成對真實無限期偏差的精確因果分解。
- 保存 `results/direction2/trunc_bias.json` 及 `postmain/*tail_raw.json`，逐 seed 數值可重算。

## 策略消融（r=0.5）

- 原定三個 run 全部保留。每個固定 checkpoint 各做七個不重訓干預：去除當前型別 [0,1]、暫停／資格 [2,3,4]、近期得標 [5..12]、近期報告偏移 [13..20]、殘差 [21,22]、慢速 EMA [23,24]；第七個只保留當前型別（移除 [2..24]）。索引是 0-based，與既有 `ablation.groups()` 一致。
- 干預方式是將該組輸入的 W1 權重設為 0，其餘權重不變；無再訓練。這是在固定策略中的功能依賴測試，不證明此資訊對所有可能策略必要；零值干預可能使原策略偏離訓練分布。
- T=100000、T_score=97500、32 個 validation seeds，三個原策略與 21 個變體同批次執行，另帶誠實對照。原策略逐 seed 效用必須與已保存 validation 一致。
- 對每項報 G、相對凍結手寫基準 D、drop=G_original−G_ablation。報名目 95% 配對 CI，並對 21 個 drop 提供 Bonferroni 同時區間。只有同時區間下界>0 且 drop≥0.005，才標示「實質依賴」；0.005 是此次診斷事前選定的效應量門檻，不替代正式 MDE。
- 不因結果增加變體或重選較有利的 run。保存所有快照和逐 seed 差值，輸出 `postmain_ablation.json`。

## 行為紀錄（r=0.5）

- 三個原策略、凍結手寫基準、誠實策略；validation 的前 8 個 seeds、T=20000。摘要取 t=2501..17500，排除開始 2500 輪及記分窗外尾段；此短軌跡只作描述，不與正式 100000 輪得分混用。
- 保存公開日誌 z1、u1、v1、won1、susp1；不把其他 agent 的型別或私有稽核狀態傳給策略。記錄全程公開觀察重建的一致性，以及記錄功能開／關不改變快照的短 GPU 驗收。
- 描述符合服務資格時，各 u 區間的平均 v−u、誇大／縮小比例、得標比例，及暫停時的報告行為。區間固定為 u 每 0.1 一格；另外按資格／上一輪是否得標分組。條件分組只有關聯意義；因果解釋以消融為輔，不能單憑分組均值下結論。
- 保存壓縮的完整公開軌跡與逐 seed 摘要；所有數字均標示為探索性。若觀察到新形態，只提出後續假說，這批不追加追著結果跑的實驗。

## 執行與驗收

學校單一 GPU 程序、float64；只在已支援且短驗收一致的純 MLP 消融批次用 CUDA Graph，尾端變體與公開日誌用 eager。小型 CPU／GPU 驗收使用訓練 seeds。先提交本協定與入口，再執行診斷；每階段原子保存、可續接、備份。完成後在學校 CPU 從快照與公開軌跡獨立重算報告，再取回本機。
