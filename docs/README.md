# 專案文件入口

這個專案研究稀缺資源分配中的自報需求與策略性誇大。三個階段的模型、問題和證據不同；請先看各階段的結果，再回查設計與歷史紀錄。

| 想了解什麼 | 從這裡開始 | 證據與規格 |
|---|---|---|
| 現在正在做的學習型攻擊評估 | [方向二入口](direction2/README.md) | [凍結規格](direction2-spec.md)、[凍結登記](direction2-freeze.md) |
| 固定稽核與手寫攻擊的比較 | [方向一結果](direction1/results/summary.md) | [數字稽核](direction1/results/number-audit.md)、[論文草稿](direction1-paper/paper.pdf) |
| 移動服務、距離成本與資訊價值 | [空間派遣入口](dispatch/README.md) | [主張與證據](dispatch/claims.md)、[論文草稿](paper/paper.pdf) |
| 專案為何改變方向 | [整體決策紀錄](project/decisions.md) | [文獻](project/literature.md)、[後續方向](project/future-directions.md) |
| 怎麼在學校機器執行 | [部署手冊](../deploy/README_zh.md) | [正式評估協定](direction2/design/main-evaluation.md) |

`direction2/` 分成 `design/`（設計與實作）、`results/`（結果）、`reviews/`（審查）、`history/`（過程紀錄）、`archive/`（已淘汰但保留的材料）。方向一採相同分類。原始數據仍集中在 repository 的 `results/`，不複製進文件目錄。

`direction2-spec.md` 與 `direction2-freeze.md` 保留原路徑和原始內容，以維持凍結憑證、檔案雜湊和評估入口的一致性。公開的 `paper/`、`direction1-paper/`、`demo/`、`demo2/` 網址也保留。歷史規格、原始結果 JSON、設計者操作日誌及舊程式註解可能引用搬動前的文件名稱，對照 [搬移索引](file-map.md) 即可查到現址；原始證據中的路徑不做事後改寫。
